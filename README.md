## 📁 Featured Projects

### 🍽️ Mezzanine Restobar (SWGCMDEM) — Enterprise ERP & CRM
*Comprehensive enterprise platform (public landing page + administrative CRM dashboard) for a criollo restaurant in Lima.*
- **Context:** Course Project (Sistemas de Información Empresarial II)
- **Stack:** PostgreSQL (Supabase) · Node.js/Express.js (Railway) · React/Vite (Vercel) · Tailwind CSS.
- **Key Features:**
  - Designed and refactored over 2 months of continuous development cycles.
  - Implemented technical SEO (`react-helmet-async`, dynamic sitemaps, robots.txt, Google Search Console integration).
  - Built a dynamic menu manager (CRUD) connected to Cloudinary.
  - Designed HR modules, client tracking (LTV), legal compliance pages, and a persistent database guest book.

### 🍽️ Mezanine - NoSQL Reservations System
*Functional backend prototype oriented towards NoSQL document-based reservation management.*
- **Context:** Course Project (Bases de Datos II)
- **Stack:** MongoDB Atlas · Node.js/Express.js · React/Vite · Tailwind CSS.
- **Key Features:**
  - Developed in a single day, focused on advanced MongoDB features:
    - **Capped Collections:** Log performance optimization via a 1MB capped collection (`auditoria_logs`) with TTL.
    - **Native Views:** Live data filtering using native database views (`v_reservas_hoy`).
    - **Mongoose Triggers:** Application-level hooks for automated audit logs upon reservation updates.
    - Aggregation pipelines to calculate hourly customer density.

### 💼 DUXCalc Payroll System
*High-security payroll calculation and campaign management system for a contact center.*
- **Context:** Collaborative Multi-Semester Integration Project (10th-cycle thesis).
- **Role:** Frontend Developer & UI-UX Collaborator.
- **Stack:** React · Node.js · Firebase (Firestore & Storage) · Nodemailer.
- **Key Features:**
  - Implemented a secure password recovery flow using OTP codes (cifrados con bcrypt), email dispatch via Nodemailer, and backend rate limiting to mitigate brute-force attacks.
  - Redesigned and polished UI/UX using **Nielsen's Heuristics**, transforming a basic interface into an accessible, responsive, and intuitive application.
